## 平台角色

| 能力 | ROOT | 平台管理员 | 普通用户 |
| --- | --- | --- | --- |
| 管理平台管理员（授予/撤销 platform_admin） | 是 | 否 | 否 |
| 创建普通账号（管理接口） | 是 | 是 | 否 |
| 撤销指定用户全部会话 | 是 | 是 | 否 |
| 修改/删除 ROOT | 否（ROOT 自身也需受控流程） | 否 | 否 |
| 转移 ROOT 身份 | 仅专用引导/恢复流程 | 否 | 否 |
| 创建团队 | 是 | 是 | 是 |
| 查看所有团队（显式管理接口 `/api/v1/admin/teams`） | 是 | 是 | 否 |

约束：

- `users.system_root` 为唯一真值，ROOT 身份不通过用户名、昵称或团队角色推断。
- `waiting` 只作为初始 ROOT 身份标识；创建同名普通账号不能获得权限。
- 普通业务接口不得修改 `system_root`、ROOT 内部 ID 或唯一性约束。
- ROOT 操作写入专门审计事件。
- **ROOT 不默认绕过团队业务数据授权**：团队业务接口对非成员（含 ROOT）返回 404；平台级可见性仅通过显式管理接口实现。紧急跨团队例外机制须另行设计（明确、受限、可审计），本阶段不实现。
- 不开放匿名公众注册；账号来源 = ROOT 引导 + 授权创建 + 内部邀请（PRD V1.0 账号与注册策略）。

## 团队角色

| 能力 | 所有者 | 管理员 | 成员 |
| --- | --- | --- | --- |
| 编辑团队信息（Phase 02 未实现，后续阶段） | 是 | 是 | 否 |
| 邀请成员（仅限已存在账号，admin/member 角色） | 是 | 是 | 否 |
| 取消邀请 | 是 | 是 | 否 |
| 移除成员 | 是 | 是（不能移除所有者） | 否（可自我退出） |
| 分配团队角色 | 是（可授予所有者） | 是（不能授予所有者，不能变更所有者） | 否 |
| 查看团队成员与邀请 | 是 | 是 | 成员列表可见；邀请管理不可见 |
| 创建项目（Phase 03） | 是 | 是 | 否 |
| 查看团队项目（Phase 03） | 是 | 是 | 是 |
| 管理奖金方案（V2.0） | 是 | 是（需授权） | 否 |

团队角色是 `team_members.role`，同一用户在不同团队可有不同角色。团队创建者自动成为 owner；允许多 owner；任何变更不得使团队失去最后一名 active owner（数据库触发器 + 事务行锁）。团队 owner 不映射为平台管理员。

成员加入必须经邀请接受流程：邀请具备授权、有效期（默认 72h，1–168h）与接受人身份约束，仅被邀请者本人可接受/拒绝；不允许仅凭任意用户 ID 未经授权加入。

| 能力 | 项目负责人 | 项目参与者 |
| --- | --- | --- |
| 编辑项目 | 是 | 否 |
| 管理任务与依赖 | 是 | 受限（仅负责的任务） |

## 授权检查顺序

```text
认证身份
  → 资源所属团队（从 URL/路径解析，且与数据库记录一致）
  → 团队成员关系与状态
  → 团队角色
  → 项目成员关系与角色
  → 具体操作权限
  → 资源状态（是否归档、是否终态）
```

规则：

- 授权在后端 Service 层执行，Handler 不重复实现规则，前端隐藏按钮仅用于体验。
- 查询必须带 `team_id`，不能先查资源再判断。
- 跨团队访问返回 404。
- 批量接口逐项校验，任一项越权则整体失败（Phase 02 无批量接口；出现时必须满足）。
- 已移除成员的会话不保留历史敏感数据访问权；成员关系每次请求实时查询，移除即时失效，其他 Team 访问不受影响。

### 授权响应映射（ADR 0004 实施细则）

| 情形 | HTTP | 错误码 |
| --- | --- | --- |
| 未认证 | 401 | `unauthorized` |
| 无该 Team 访问权（含资源不存在，统一措辞） | 404 | `not_found` |
| 有 Team 访问权但操作权限不足 | 403 | `forbidden` |
| 状态冲突 | 409 | `conflict` |
| 参数非法 | 400 / 422 | `bad_request` / `validation_failed` |
| 登录限流 | 429 | `rate_limited` |

## 会话安全

决策已固化于 [ADR 0006](adr/0006-auth-session-security.md)：

- 密码使用 Argon2id（t=3、m=64MiB、p=4，参数经本机基准测试记录）。
- 会话使用 HttpOnly、SameSite=Lax 的短期 Cookie（默认 12h 绝对过期）；Secure 在 production 强制、由环境派生，无降级开关；不把长期高权限令牌放入 localStorage。
- 会话令牌 32 字节安全随机，数据库仅存 SHA-256 摘要；登录签发新令牌防会话固定。
- 登录失败限流（IP+用户名滑动窗口，默认 15 分钟 10 次）；会话支持撤销（退出、管理员撤销）。
- CSRF：SameSite=Lax + 变更请求自定义头 `X-Nexora-CSRF: 1`，API 不启用 CORS；有集成测试覆盖。
- 敏感操作重新认证：Phase 02 未实现，列为后续阶段候选（已知限制）。
